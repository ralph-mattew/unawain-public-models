# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Use one of these channels:

- Open a private security advisory on GitHub
- Email the maintainers listed in repository settings

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if available)

## Response Expectations

- Initial response target: within 72 hours
- Triage and severity classification: within 7 days
- Patch timeline: based on severity and exploitability

## Scope

This policy covers:

- Repository scripts and release pipeline
- Published manifests/checksums
- Artifact integrity and supply-chain concerns

This policy does not cover upstream framework vulnerabilities (PyTorch, coremltools, transformers), which should also be reported upstream.
