# Responsible Use

## Intended Use

These models are intended for:

- On-device language processing and summarization
- Translation and summarization support in productivity workflows
- Research and development within stated model limits

## Not Intended For

- High-stakes autonomous decisions (legal, medical, financial)
- Content moderation without human review
- Uses requiring guaranteed factual accuracy

## Known Limitations

- Model quality is domain and language dependent.
- Quantization can reduce quality on edge cases.
- Performance and accuracy vary by device and OS version.

## Safety Practices

- Keep a human in the loop for critical outputs.
- Add confidence checks and fallback pathways.
- Evaluate with representative multilingual datasets before deployment.

## Privacy

- Favor on-device inference for sensitive content.
- Do not log raw user inputs unless strictly necessary and consented.
